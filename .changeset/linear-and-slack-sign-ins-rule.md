**Somebody who signs in with Linear or Slack now rules from there with no linking step**, as somebody who signs in with GitHub already does from github.com. A Linear sign-in counts for comments in the workspace it was to. A Slack sign-in counts for button clicks only when Slack's sign-in named the Slack Socket's own team. A guest from another team in a shared channel still needs a link code. Everybody else links as before: Linear on Linear's own page, Slack with the code Slack sends them. See ADR-0027.
