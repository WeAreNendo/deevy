A keyboard shortcut drawn beside the thing it triggers, in `Kbd` keys: `mod+k` is one combination (⌘ K on a Mac, Ctrl K elsewhere), `g r` a chord of two keys in sequence ("G then R"). It is decoration (`aria-hidden`), so put it beside a label, never instead of one: at the end of a sidebar row, under a Gate's Note, in the shortcuts sheet. The app's keys: `mod+k` the palette, `?` the shortcuts, `g r` Runs, `g w` Work, `g p` Projects, `g s` Settings, `shift+a`/`shift+r` to choose a ruling on a Gate and `mod+enter`, the only submit key, to commit it.

```tsx
<Shortcut keys="mod+k" />
<Shortcut keys="g r" />
```
