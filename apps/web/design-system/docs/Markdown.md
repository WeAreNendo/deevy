What Humans and Agents write, rendered from markdown: a Proposal on a Gate, a record's body as its tracker has it, a Ruling's note. The typography is fixed (14px/24px, headings 20/16/14, links in `text-link`, code in mono on `bg-muted` coloured by lowlight, task lists, tables, blockquotes). Use it for any body text a Member wrote; never re-style prose by hand. It is read-only: deevy has no editor, because the record is the team's, in their tool.
