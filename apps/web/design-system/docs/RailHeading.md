The name of a section in a page's rail — the 18–22rem column beside a Run, a Gate or a record: 12px, medium, muted, the size deevy sets metadata in. A heading in the main column is 14px and up; a rail's label is not one of those. Where the rail holds what a Human acts on (a Gate's ruling card, a Run's Gates) it comes first on a phone (`-order-1 @3xl:order-none`).

```tsx
<section className="flex flex-col gap-2">
  <RailHeading>Gates</RailHeading>…
</section>
```
